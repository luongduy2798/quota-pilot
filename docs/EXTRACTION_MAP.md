## Verified protocol details and limits

- Codex OAuth client `app_EMoamEEZ73f0CkXaXp7hrann`; built-in `http://localhost:1455/auth/callback` belongs to its local companion service, not the dashboard callback. The app supports configuring another registered URI and pasting a full callback URL. Cloud browser must reach the configured redirect. Verify registration with provider before deploying; local install alone cannot establish whether that client ID accepts an arbitrary hosted URI.
- React/Vite deploys as static Worker assets; Worker owns auth, D1, OAuth exchange, quota and scheduled calls. Cloudflare Cron Triggers run every minute with a 2-due-schedule cap per tick. D1 uniqueness/transactional batches claim each `(schedule_id, occurrence_at)`. Requests over five minutes late become `missed`; no catch-up invocation occurs.
- Custom provider destinations require exact `CUSTOM_PROVIDER_HOSTS` entries. DNS A/AAAA are checked against public address ranges immediately before a request; redirects are forbidden. Cloudflare's edge does not expose socket-level egress pinning, so a DNS-rebinding-resistant general arbitrary-host proxy is intentionally outside the design.
- The default Worker deployment has a placeholder D1 ID and no custom domain binding. Local `npm run dev` creates a fresh local D1 database. Register an empty production D1 binding and `quota.chillix.me` hostname only when the user requests deployment; root `chillix.me` belongs to the Chillix License Server.
